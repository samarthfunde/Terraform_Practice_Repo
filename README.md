# Terraform EC2 Practice Repository

This repository is created for Terraform practice purposes.

## What this repository contains
- ec2.tf  
  - Terraform configuration to create an AWS EC2 instance
  - Used only for learning and hands-on practice

## How to use

```bash
terraform init
terraform plan
terraform apply
Notes
AWS credentials are not committed to this repository

This is a practice repository

Code will be updated continuously after completing new tasks

Purpose
Learn Terraform basics

Practice EC2 provisioning

Understand Infrastructure as Code (IaC)
```
